# 演示任务：真实安全 Issue 修复（脱敏版）

## 背景

公开仓库 `pulsing-forge` 的一项安全审计待办：仓库内硬编码了内网代理地址与平台凭据格式。任何外部读者都可以从中获取内网地址与凭据的使用方式。

涉及文件：

1. `mock/mini_proxy.py` —— 第 28-29 行硬编码内网代理地址（凭据拼接后访问）；
2. `docs/sandbox-llm-access.md` —— 多处内嵌该地址与凭据格式；
3. `compare/check_sa.py` —— 附加硬编码密令。

> 文中所有内网地址均脱敏为 `10.x.x.x`。

## 要求

- 清除全部硬编码，改为从环境变量读取（未设置时回退本地安全默认值）；
- 改动最小化，不得删除无关逻辑；
- 保持功能可用（编译/语法通过，核心函数数量不变）。

## 期望流水线

| 阶段 | 执行者 | 产出 |
|---|---|---|
| A 诊断 | e3（审计）、e4（方案） | 泄露审计报告、修复方案 |
| B 修复 | e2（Aider） | 3 个文件改动 + diff 回执 + 本地机械验证 |
| C 审查 | e1（Claude，独立审查） | verdict=PASS/CONCERNS + 修改边界 |
| D 自愈 | e5（终验）、e6（重修） | 最小重修 + 新增验收门 |

## 验收标准

- `grep` 内网地址残留 = 0
- 核心函数数量修复前后一致
- `py_compile` / 编译通过
- 账本完整（约 20 封信）可回放
